HANGUL QUEST is a Korean language learning game operated by bitrium2022. Effective date: November 27, 2026.

Game data

The reviewed game version stores vocabulary progress in your browser's local storage. You can delete this progress by clearing site data in your browser. The reviewed game does not require account registration or payment.

External services

The site is hosted on GitHub Pages and loads some images from Unsplash. These providers may process IP addresses, browser information and request logs under their own privacy policies: GitHub and Unsplash. Pronunciation uses your browser's speech synthesis feature, which may rely on your device or browser provider.

Contact and choices

Changes

We will update this policy before introducing features that change how personal information is processed.
